# JP Galinato Marketing Portfolio

GTM Engineering, Demand Generation, people-led solutions and technology.

## Cloudflare Pages

Connect this repository to a Cloudflare Pages project.

- Production branch: main
- Framework preset: None
- Build command: python3 scripts/build-blog.py
- Build output directory: dist

## Blog updates

Edit content/posts.json and run python3 scripts/build-blog.py. Commit the updated content and generated dist files. Once connected, Cloudflare Pages deploys commits automatically.
